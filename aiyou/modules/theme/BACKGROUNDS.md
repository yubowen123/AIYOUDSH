# AIYOUDSH 主题配置与主体背景

静态背景由原生三栏框架的 CSS background 绘制，视频作为同一框架内不可交互的装饰层（pointer-events:none）。主聊天、macOS 中间列、右侧列和原生输入区渐变分别适配，收发气泡、导航、输入框保持独立透明度。预览、取消、系统默认和卸载同时清理主题样式、播放器和监听器。

机甲使用 AIYOUcodex 原 `assets/background.png`（1280×720），其余软糖、海岛、海边、YOYO 使用原主题的静态插画。资源来源与 SHA-256 见 `assets/provenance.json`。原有插画的权利说明随资源保留，代码许可不转授第三方角色权利。

小新主题原本是用户提供的相册；海绵宝宝主题原素材也是用户提供的参考图片。本交付未复制这两项用户媒体，使用独立绘制的中性纸纹/海浪静态 SVG 回退，主题面板明确显示区别。

机甲默认使用原主题 `assets/running.mp4` 真实 H.264 循环视频（1280×720，4 秒，3,214,522 字节，无音轨）。视频失败、窗口隐藏、减少动态效果、关闭动态或选择静态图片时回退静态图；取消和主题切换释放视频 src、暂停播放、移除监听器。本次未移植原版进入/点击/发送/运行/完成/错误事件状态机、声音和轮播；不把静图平移冒充原视频动画。图片失败时仍有主题纯色底，不影响聊天操作。

## 真实配置页与持久化

“主题与动效配置”提供背景模式、显示方式、背景位置与显现强度、动态开关、15 项分层透明度和 13 项配色。透明度为 `100*(1-alpha)`，输入框内部与外层分别控制，整体表面透明度不降低文字透明度。输入框、面板、菜单、聊天底层、气泡、卡片与边框通过各自语义材质生效。

点选和拖动立即本地预览；取消或关闭页面恢复已保存设置；“恢复本主题默认设置”先预览原始默认，仍需点击保存。选择“系统默认”恢复宿主原生外观。每个主题独立保存配置，切换不覆盖其他主题。自定义配色和透明背景可能降低对比度，页面明确提示结合背景检查文字。

`GET /aiyoucodex-dsh/theme` 返回当前主题和 revision。`POST /aiyoucodex-dsh/theme/select` 接收 `{id,options,ifRevision}`；options 包含 motion、alpha、colors、background。主题 JSON 由旧 active 选择无损迁移至 schemaVersion 2，保留旧字段；每个主题的 options 分别存储，写入队列与原子替换避免并发损坏，过期 revision 返回 409，不覆盖新设置。配置只允许已知键、六位 HEX、合法枚举与明确数值范围。

## 手工配置本地用户背景

用户主题 JSON 位于 `${DSH_HOME}/aiyou-enhancer/themes/<id>.json`。在其 `background` 字段声明：

```json
{"file":"wall.png","fit":"cover","x":75,"y":50,"opacity":0.46}
```

图片应放在 `${DSH_HOME}/aiyou-enhancer/themes/<id>/assets/wall.png`。仅接受 PNG/JPEG/WebP 普通文件，单文件不超过 10 MB。不接受远程 URL、绝对路径、目录穿越和跨目录软链接。对比度、其余主题身份仍按现有主题合同校验。主题面板刷新后预览/保存；没有图片的用户主题继续使用纯色材质。本次没有提供上传图片的面板。

资源请求走 `/aiyoucodex-dsh/theme/media?id=<id>`；原机甲视频额外使用 `slot=loop`。资源仍使用宿主登录、Host/Origin 校验，不开放匿名文件服务。支持 GET、HEAD 与单段 bytes Range（206/416）以支持播放器定位，只读取声明资源，单文件不超过 10 MB。
