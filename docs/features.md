# 功能、入口与当前边界

[返回首页](../README.md) · [源码模块详表](../aiyou/FEATURES.md)

AIYOUDSH 的基础结构是左侧功能栏、可独立折叠的会话列表、中间聊天和右侧工具区。打开工具保留当前聊天；再次点击当前工具可收起右栏。

## 导航与对话

| 位置 | 功能 |
| --- | --- |
| 左侧会话列表 | 置顶、项目、最近、中断；搜索、项目目录筛选、摘要、标签、三色标注 |
| 最左侧功能栏 | 新对话、Agent 工作区、Skills、资产控制台、模型竞技场、项目管理、主题配置、MOKE 及宿主工具入口 |
| 对话顶部右侧 | **用量与上下文**、**输出目录**；按钮跟随当前原生会话身份 |
| 设置与工具 | 任务上下文、输出偏好、对话副本、主题配置、服务信息 |

窗口和界面品牌为 AIYOUDSH，官方 `.app` 与 macOS 应用菜单保留 DeepSeek Harness 名称。Claude Code 功能模块已从本增强中移除。

## 随包功能

最终安装 **15 个模块**：2 个原生界面模块和 13 个功能模块。功能源码目录保留 14 个模块，其中 `session-state` 是未启用的参考实现；实际会话标记由原生 workspace 统一管理。

| 功能 | 当前行为 | 使用边界 |
| --- | --- | --- |
| 主题配置 | 七套内置主题；背景、分层透明度、配色；预览、取消、保存、系统默认 | 机甲视频循环；其他静态或中性回退，见[主题清单](themes.md) |
| Skills | 有界元数据检索、自动分类、自定义分组、收藏 | 默认读取本 DSH profile 的 Skills；对话提及 Skills 不等于导航命令 |
| 资产控制台 | 本地项目与分类、分页检索、媒体预览、提示词、文本编辑、角色关联、元数据和文件操作服务 | 模型调用、3D 与节奏处理尚未适配宿主执行通道；相关接口返回不可用 |
| 项目管理 | 本地 SQLite 服务、六泳道看板、项目、任务、评论和工作流 | 看板自身的 AI Chat 执行通道未接入 |
| 用量与上下文 | 呈现宿主实际记录的用量、上下文和耗时 | 缺失值显示未知，不从其他字段估算成事实 |
| 输出目录 | 当前会话身份、目录绑定、命名、所有权标记、输出规则与定位 | 仅操作当前会话明确绑定的目录 |
| 任务上下文 | 分别呈现宿主投影事实和提取草稿，可确认保存版本化草稿 | 提取内容不自动成为已确认事实 |
| 输出偏好 | 全局、项目、会话继承，接入原生 system-prompt section | 仍遵循宿主权限和模型配置 |
| 对话副本 | 导出当前会话的用户/助手可读文本 | 不导出内部 reasoning 或 tool-call |
| Agent 工作区 | 用户点击检测后收集有界程序/内容元数据 | 不自动扫描、执行其他 Agent 或迁移其内容 |
| 发布追踪 | 本地分类、上下文压力显示；可配置 feed | 网络轮询默认关闭，需用户明确开启 |
| 模型竞技场 | 显式配置 `AIYOU_ARENA_MCP_URL` 后，读取目录并提供提交准备与确认流程 | 未配置时报错，不猜测其他 profile 或凭证文件 |

本地资产和看板服务随包提供，打开对应工作区后才启动；不需要另一个 AIYOUcodex 应用后台。Laya 语义检索依赖单独的本地模型/运行时，未配置时报告回退或不可用。

## MOKE AIGC

点击 MOKE 菜单会在当前对话的**官方原生 Browser 标签页**中打开 [MOKE 官网](https://www.mokeaigc.ai/)。地址栏、前进、后退、刷新、加载错误和外部打开能力保留。

同一对话再次点击会聚焦或收起已有 MOKE 标签页，不反复重载当前页面或接管其他浏览器标签页。关闭后再点会新建；不同对话各自拥有标签页。扩展持久保存的是有界的“会话 ID—标签页 ID”归属信息，并在使用前与宿主真实标签页清单核对。

登录、Cookie、页面内容和表单由网站及官方 Browser 管理，本增强不复制凭证或注入站点脚本。跨重启能否恢复站内位置、登录状态和未提交表单，取决于宿主 Browser 与网站行为；本增强没有承诺完整页面状态恢复。遇到登录或弹窗限制，可用原生“外部打开”继续访问。

## 验证覆盖

v0.4.0 的验证包括源码构建、结构核对、安装器隔离测试及实际安装重启后的界面检查。原生导航、主题配置与机甲背景、MOKE 页面、顶部工具位置均属于界面验收范围。

测试与页面可见不代表所有业务操作已逐项验证。当前未据此宣称全部资产编辑、任务工作流、外部模型生成或 AIYOUcodex 功能等价；具体执行能力以上表和实际连接状态为准。
