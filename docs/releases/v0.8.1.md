# v0.8.1 素材库、可读配色与媒体通道配置

本版继续使用 macOS arm64 官方 `0.2.1-rc.2 / 332895e` 作为基线。官方应用包不修改；增强运行时安装后须完整重启官方应用才能加载。Windows 桌面本轮未实测。

## 素材库

普通素材库和画布素材选择器共用左目录、右素材布局。项目下显示关联根目录及子目录，可筛选、搜索、预览，添加现有本机文件夹并扫描；重扫同步新增、删除和变更。空目录正常显示；无法读取的目录明确降级提示，不能将读取失败当作空库或扫描成功。

目录关联采用原子追加，防止两个窗口覆盖彼此新增的路径。重复关联幂等，重叠目录素材去重。扫描不移动原件。宿主提供本机目录选择，手动绝对路径为回退；取消选择不修改目录配置。

画布内选择素材仍绑定明确项目与请求，成功保存后回执。普通库的“加入画布”先选择目标项目，不猜测默认目标；对话和项目上下文隔离。

## 配色规范

[界面颜色规范](../ui-color-standard.md) 要求控件前景、背景和边框成对定义。普通文字目标 4.5:1，大字和关键控件边界 3:1；将透明颜色与语义底色合成后校验。派生可读颜色用于徽标、离散按钮、输入、弹窗和错误提示，用户原始配置保留。作品图片、视频、图形导出及 3D 材质不参与 UI 重着色。

## 文档自动配置媒体通道

在“媒体模型”填写 API 文档或聚合平台入口与 Key，点击“自动识别并保存媒体通道”。公开文档读取不会携带 Key 或执行文档中的代码；有确定调用合同的图片、视频、配音、音乐模型自动保存为通道，其他模型列出缺项。新增服务可以先不填 Key，稍后补填保存。文字继续使用 DSH 当前模型。

识别关联文档、JSON manifest、OpenAPI JSON/YAML、公开的带类型模型目录及明确的接口元数据。模型 ID 不用于猜测能力；异步任务需要明确的任务 ID、查询路径、终态和结果字段。JSON 声明式模板支持非必填根字段与参数别名，缺少必填参数在提交前报错。

“任意平台”指通用输入和解析流程，不代表任何未知私有协议都能无证据推导。需登录才能访问的文档、纯动态页面、外部 schema、multipart 专用接口、缺少响应或轮询合同、仅识别/转写用途的模型会显示待补原因。可补充机器可读接口文档或人工映射，不会伪装为已完成。

真实 TokenLab 公开文档作为配置验收样本；配置验收和本机模拟服务传输验收不代表账户生成权限、计费请求或模型效果通过。本轮不重新提交真实媒体生成，也不使用测试接口作为最终内置供应商。
