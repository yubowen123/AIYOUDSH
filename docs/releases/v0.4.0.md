# AIYOUDSH v0.4.0

为官方 DeepSeek Harness 增加可卸载的工作台、主题与创作入口。本版完成主题配置、品牌、Claude Code 移除、MOKE 菜单及对话顶部工具位置五项集中调整。

## 下载

- [macOS arm64 安装包](https://github.com/yubowen123/AIYOUDSH/releases/download/v0.4.0/AIYOUDSH-v0.4.0-macos-arm64.zip)
- [可构建源码包](https://github.com/yubowen123/AIYOUDSH/releases/download/v0.4.0/AIYOUDSH-v0.4.0-source.zip)
- [安装、升级与卸载](../installation.md)

## 变化

- 界面与窗口标题统一为 AIYOUDSH；官方应用包保留原名。
- 七套主题配置支持预览、取消、保存、系统默认和每主题独立配置；可调背景、14 项透明度和 13 项颜色。
- 机甲接入真实 4 秒 H.264 视频循环，含静态回退与减少动态处理。
- MOKE 使用官方原生 Browser；同对话标签复用，保留原生导航工具。
- 用量与上下文、输出目录位于当前对话顶部右侧。
- 移除本增强的 Claude Code 模块和菜单，清理拥有的旧连接与遗留标签页。

## 兼容与范围

精确支持官方 `0.2.1-rc.2`、构建 `332895e0f7c9d4dbfb29729f5eb367fa263ff986`。当前安装包为 macOS Apple Silicon（arm64），本地 ad-hoc 签名；源码构建要求 Node.js 24。最终运行库为 15 个模块。

机甲动态当前是循环背景，未接入七状态事件动效、声音、轮播或媒体上传面板。其他主题为静态图或明确标注的中性回退。部分资产/看板的模型执行与语义检索仍需要额外适配或配置，详见[功能说明](../features.md)。

源码是可编辑 JavaScript 恢复分区、新增扩展和本地业务服务，不是完整官方 TypeScript 工程或可独立启动的官方 fork。
