# v0.8.3 审查与剩余事项

日期：2026-10-26。基线为本地 v0.8.2，修复版本 v0.8.3；下列为本地与隔离官方宿主证据，不代表所有模型或全部平台已验收。

## 本轮发现与处理

优先级 P1 表示可能误操作、覆盖数据或阻断继续使用；P2 表示反馈、恢复或日常操作体验存在明显缺口。下表按问题组汇总，避免把同一缺陷的多条测试当成多个功能。

| 问题组 | 影响 | 本轮处理 |
| --- | --- | --- |
| P1 辅助面板未绑定明确对话 | 任务上下文、输出目录、副本可能读到最近更新的其他对话，输出偏好对话层可能传空 ID | 从原生标签页读取身份；未确定目标不写入、不导出、不打开别的目录；忽略过期响应。用量优先突出指定对话并保留真实全局汇总 |
| P1 上下文保存竞态与字段完整性 | 保存期间新改动可能被误标已保存，扩展的约定/参考字段可能清空 | 保存使用完整快照、会话及编辑版本保护，失败保留草稿；保存期间禁用相关冲突操作 |
| P1 同一上下文跨窗口覆盖 | 两窗口从同版本编辑，后保存可无提示覆盖先保存 | 加每会话串行写入与版本比较；冲突保草稿并呈现最新保存内容，明确确认后再以新版本保存，仍检查冲突 |
| P2 “恢复自动提取”没有真正恢复 | 已有 saved 时重新读取仍优先 saved，按钮不改变草稿 | 独立 fresh 读取不写磁盘，恢复后标记待保存 |
| P2 Skills 失败丢草稿或错误不可见 | 创建失败表单消失，详情页操作失败无反馈 | 只在成功后清输入；列表和详情都显示错误；失败可继续编辑 |
| P2 Skills 星标键盘动作错误 | 在收藏按钮按 Enter/Space 可能打开卡片详情 | 卡片仅处理自身键盘事件，内嵌按钮保留原生行为 |
| P2 倒计时静置不更新 | 跨过公告时点仍显示几分钟后 | 本地时钟驱动显示，卸载清理计时器；到时仍只写待核验，不宣称到账 |
| P2 项目和创作工具假加载 | 请求失败仍显示正在读取；恢复成功后旧错残留 | 加载、失败、空结果互斥，提供重试并清除旧错 |
| P2 素材弹层缺少键盘与焦点管理 | Tab 可进入被盖住的画布，关闭后失去操作位置 | 局部 dialog 包含 owned iframe 的 Tab/Shift+Tab 循环与 Escape；覆盖区 inert，关闭恢复触发位置，嵌套弹窗优先；保存中不假装取消写入 |
| P2 模型设置草稿无保护 | 切服务或刷新静默丢输入；删除直接执行 | 明确未保存状态，切换/刷新可取消放弃；删除先确认，失败保草稿；临时服务移除后准确说明原保存服务恢复 |
| P2 共享画布音视频误作图片 | 查看者看到破图而不能播放 | 原始快照保留媒体类型，镜像使用对应播放控件；不自动播放、媒体控件不拖动画布 |
| P1 迟到画布回执堵塞命令 | 超时后回执被拒，游标无法推进，后续命令也超时 | 区分执行失败与传输失败；明确过期回执推进游标，网络不确定时复用原回执，避免重复执行 |
| P1 素材导入误认其他新节点 | 同时手工新建一个节点可能让未完成的素材导入误报成功 | 新节点的原件引用经统一 Gateway 别名解析，必须匹配选中的 canonical 原件 |
| P1 项目目录写入失败后内存先变 | 磁盘仍旧名称，但当前界面已展示新状态 | 串行 clone-on-write，原子保存成功后才发布状态，返回值也隔离 |
| P1 素材改名中途失败破坏引用 | 文件已改名、登记未更新，重扫产生新身份绕过旧引用保护 | 先落改名意图，再改文件；失败回滚原件/旁文件/元数据；重启校验原件哈希并恢复同一 ID 与引用保护 |
| P1 临时模型配置误伤持久凭证 | 临时切 API、清 Key、删除 overlay 或转持久可能影响隐藏原服务 | 临时作用域与持久绑定隔离；独立返回 sessionOnly，不把 Key 的存储位置当配置作用域；显式转持久校验实际目标绑定 |
| P2 多产物恢复重复依赖旧下载地址 | 第一项已成功入库、第二项失败，恢复仍需旧签名地址，可能无法继续 | 每项成功立即保存路径/哈希/身份检查点，恢复校验复用原件后再处理剩余项，不重新提交生成 |
| P1 模型竞技场准备与提交不一致 | 准备 A 时编辑成 B，迟到响应可重新启用确认，实际提交与预览不同 | 输入版本和请求序号挡住旧响应；服务端票据固定原 spec 与幂等标识，按对话/面板绑定，有 TTL 和数量上限；重复提交不重复发送。未配置、空目录、读取失败分别显示且可重试 |

上述缺陷使用隔离数据或确定性本地响应复现。真实模型生成、账户权限或第三方最终计费不在本轮证据中。

## 仍需完善的地方

以下没有混写成“已修复”。“设计机会”表示现有功能可以工作，但使用成本偏高；“覆盖缺口”表示本轮未完成相应验收，不等于已证明该功能坏掉。

| 优先顺序 | 类型 | 当前不足与影响 | 建议落地方式 |
| --- | --- | --- | --- |
| 1 | 已观察的 UX 不足 | 连续从素材库插入图片、视频、音频会采用相同中心落点，节点相互遮挡；隔离官方宿主中已观察到 | 给新导入提供可预测的错位/空位排布与“定位刚插入节点”，保留手动放置。需要结合画布缩放、锁定节点和批量导入设计，不擅自重排已有作品 |
| 2 | 设计机会 | 画布项目列表以名称/时间卡片为主；项目变多后缺少搜索、筛选与直观封面 | 搜索名称、最近/名称排序、封面、最近项目快捷返回；大列表分页/虚拟化另做规模验证 |
| 3 | 设计机会 | 工作区、画布项目、素材来源项目和任务项目都叫“项目”，跨入口容易选错 | 在选取器中明确“画布项目 / 素材来源 / 工作区”，持续显示当前目标；保持底层 ID 不变 |
| 4 | 设计机会 | 媒体参数高级配置仍需编辑 JSON；缺少按参数类型的可视化编辑和字段级错误 | 文档有显式合同才自动配置；非标准、登录受限或缺失资料的平台仍需补充。保留自动发现，增加结构化参数表、必填项与能力标签；缺合同的模型保持待补，不能靠模型名字猜支持能力 |
| 5 | 设计机会 | 画布命令、模型任务、下载入库、配置检查的状态分散 | 提供统一任务入口，区分已提交/生成中/下载中/已入库/待确认/可恢复失败；重试明确只重试哪一段，保留请求标识 |
| 6 | 设计机会 | 若干辅助面板以调试字段和完整内部标识为主，新用户理解成本高 | 默认展示目标、状态、下一步和一键打开；投影版本、修订、原始统计折叠为诊断信息 |
| 7 | 设计机会 | 新用户仍需来回建立画布项目、关联目录和配置媒体服务 | 增加可跳过的本地起步清单和上下文跳转；只连接用户选择的服务，不自动提交生成 |
| 8 | 实际功能边界 | 看板自身 AI Chat、资产库旧独立模型/3D/节奏通道尚未接宿主；Laya 高级语义检索依赖独立运行时，竞技场依赖显式 MCP | 主流程优先已接通能力；未连接入口显示具体依赖与配置位置，不把这些旧通道与已保留的画布 3D/时间线混为同一能力 |
| 9 | 覆盖缺口 | 文档识别和模型映射保存不等于每个账户、每个模型可真实生成 | 使用有效配置逐模型记录实际调用、耗时、原件解码和入库结果；本轮未发起供应商媒体生成 |
| 10 | 覆盖缺口 | 没有穷举数万素材、超大画布、低磁盘空间、强制中断和外部直接移动原件的所有组合 | 建立固定规模与资源故障基准，先验证恢复和引用保护，再确定性能目标；本轮失败注入不能替代全部 OS 故障；多窗口版本保护覆盖同一宿主服务，不代表多个独立进程强行共享同一 profile 的写入已验 |
| 11 | 覆盖缺口 | 原生系统目录选择窗口的成功选中链路、Windows 桌面、屏幕阅读器、200% 缩放和全部主题×业务状态组合未全部验收 | 独立平台/无障碍验收清单；现有桥接取消/过期回执、手动目录路径及关键主题规范证据分别保留 |
| 12 | 兼容边界 | 增强包精确依赖官方 rc.2 基线，新官方版本不能直接视为兼容 | 保留安装器版本/哈希保护，为每次官方更新做独立兼容验证；不要绕过校验更新 |
| 13 | 设计机会 | 模型表单已保护服务切换/刷新，但关闭整个插件页或退出应用时，未保存草稿没有跨生命周期恢复 | 对非敏感字段提供显式草稿恢复；Key 继续仅在内存，不把未保存的秘密写磁盘；结合宿主关闭事件做清楚提示 |

本轮保留机甲的钢蓝/石墨内容面、冰白正文与小面积冰蓝交互。配色仍按前景/背景/边界成对处理，未给图片、视频、3D 或导出作品重色。既有七套主题和系统模式的历史可读性证据可作参考，本轮没有把它们重复计作新的全部业务验收。

## 验证范围

- 源码测试 375 项：374 通过、1 项 Windows 专属 junction 检查在 macOS 跳过，0 失败/取消；独立源码包离线重建重复得到相同结果，不重复累加。
- macOS arm64 官方 `0.2.1-rc.2 / 332895e` 隔离宿主：8 项素材核心链路、9 项协同/会话/CAS/交互链路、3 项完整重启读回；打开 15 个面板未观察到 pageerror。各检查有交集，不视为全部业务功能的独立验收数。
- 两处运行目录与 YAML 一致，原安装包 CRC 通过。发布文档与知识卡片的后续更新不改变运行逻辑；最终归档校验见 Release 的 SHA256SUMS。
- 18 个安装模块包含 16 个有效功能包与 2 项原生覆盖。源 manifest 为 17 项，其中旧 session-state client 不分发；16 份源 client 中 15 份为当前活动客户端。
- 未提交供应商媒体生成，未读取用户 API Key，未操作正式项目数据。模型权限、效果、完整 Windows 桌面、超大数据与全部无障碍组合仍需单独验收。

可复现入口：`npm run build`、`npm test`、`npm run verify`。关键失败恢复回归在 `test/canvas-reliability-recovery.test.mjs`、`test/session-context-cas.test.mjs`、`test/model-arena-server.test.mjs` 与 `test/canvas-model-service.test.mjs`。
