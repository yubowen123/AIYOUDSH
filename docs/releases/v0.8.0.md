# v0.8.0：插件主题与画布外观统一

[返回首页](../../README.md) · [主题设置](../themes.md) · [功能范围](../features.md) · [画布融合说明](../integration/aiyouplus.md)

本版围绕官方 DeepSeek Harness 中的 AIYOUDSH 插件界面更新，不创建另一套应用、账号或素材库。七套内置主题保留，另外提供系统默认；本说明记录源码行为与已留存的专题证据，安装包校验、安装及重启结果由本次交付记录单独提供。

## 使用变化

- 资产库、项目看板、媒体模型、画布与创作工具使用统一主题颜色；Agent 工作区、Skills、任务上下文、用量等原生面板沿用宿主主题令牌。
- 主题可递归同步到授权同源内嵌页面，处理后挂载、导航、嵌套、切换和卸载。独立页面保留默认配色；远程、未授权页面与 `srcdoc` 不注入。
- 新增「画布与自由工具」区域，画布原有外观入口可直接定位到此处。提供 9 项颜色、4 项底色透明度、主题图/底色/透明背景、背景图强度与位置、铺满/完整显示，以及圆点/线格/隐藏网格、8–80 px 间距和网格强度。
- 配色默认跟随主题，也可手动指定，按当前主题分别保存。透明度作用于界面底色，原图、视频、预览拼图、3D 舞台和导出像素不受主题滤镜影响。画布使用声明的静态主题图；宿主机甲动态背景仍是独立静音循环。
- 系统默认读取宿主实际亮暗与计算颜色，只适配插件和画布，不覆盖宿主主题令牌；该模式仍可保存画布配置。
- 已保存的主题选择和配置同步到其他宿主窗口。本地预览不传播，远端保存不直接替换未保存草稿；页面提示刷新，取消预览采用最新保存值，保存继续执行 revision 冲突检查。

全局主题页保留 14 项透明度和 13 项颜色。七套主题的名称、背景来源及动态边界见[主题清单](../themes.md#七套主题实际包含什么)；系统默认是额外选项，不算第八套内置皮肤。

## 修复

- Agent 工作区首次打开时正确显示未检测状态，兼容检测范围的文字和数组返回；不因页面打开自动扫描。
- 画布视口外层保持透明，避免灰底遮住背景；滑块、复选框强调色随主题更新。

- 素材库菜单、文本预览、角色弹窗及页脚、状态与音频控件使用语义颜色，补齐亮暗切换。
- 媒体模型配置的输入、面板、主按钮与反色文字跟随主题，原配置及本地 Codex CLI 行为保持。
- 协同 Mirror 的底色、节点、文字、连线和强调色读取画布语义变量；创作工具与发布追踪使用有效的错误色令牌。
- 看板原生控件的 `color-scheme` 与主题一致，避免页面自身的 inline 亮暗设置覆盖插件主题。
- 系统半透明边框先与宿主底色合成，避免在插件中变成纯黑或纯白；同一子页面移除主题样式后可恢复。
- 子页面的节点拖拽样式变化不触发整树主题扫描；系统状态变化、嵌套框架和卸载仍由独立生命周期管理。

## 验证与边界

本任务交付材料中的 `DSH全插件主题适配/` 是验收目录名称，不是仓库内的相对路径。报告分别保留证据口径：

| 材料 | 用途 |
| --- | --- |
| `插件审计/插件主题审计.md`、`插件覆盖矩阵.json` | 逐插件状态、源码样式与真实页面的区别，以及 MOKE 边界。 |
| `插件审计/主题计算样式验证.json` | 实际本机素材库、媒体模型、看板亮暗计算与交互；原生信息源样式及 Mirror 呈现探针。 |
| `插件审计/主题桥只读复核.json` | 系统颜色、移除样式恢复、晚挂嵌套、观察器稳定及清理；保留修复前记录。 |
| `画布适配/主题适配交付与验证.md` | 原画布与自由工具的主题适配记录。 |
| `同步验证/`、`官方宿主验证/` | 同步与官方宿主的独立验收材料；具体执行结果以各报告为准。 |

上述材料不在本页合并成新的总通过数。源样式探针不是完整官方组件挂载，截图及主题切换不是媒体业务验收；正式宿主、安装包、安装与完整重启也分别留证。

MOKE 沿用官方 Browser 容器，跨域网站内部不注入主题。其登录、页面内容及站内外观由站点和宿主管理。

本轮没有重新发起图片、视频、音频或 Codex CLI 真实模型生成，也没有代用户登录。既有模型通道与本地处理能力的范围见[融合说明](../integration/aiyouplus.md#验证与边界)。Windows 新主题及画布能力尚未桌面实测；Mac Intel、Windows ARM 不在本轮新增支持范围。随包媒体工具的 macOS arm64 最低系统仍为 macOS 26，不能用主题检查代替媒体平台兼容验收。
