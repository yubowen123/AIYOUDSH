# v0.8.5 Key 自动配置默认媒体通道

「媒体模型」默认提供 GGWK / APIAI 通道，API 地址预填 `https://www.ggwk1.online`。首次填写 Key，点击「校验 Key 并自动配置图/视频模型」，即可读取当前 Key 的模型目录，匹配该站点的明确接口绑定并保存图片、视频模型及默认项。已有自定义服务继续保留，对话使用 DSH 当前选择的模型。

## 识别与使用

- 地址来自站点公开 `/api/status` 的 `server_address`，同一响应明确关联用户提供的 [Apifox 文档](https://apiai.apifox.cn/)。不将文档托管域名作为业务 API。
- 使用 Key 读取 `/v1/models`；另外匿名读取 `/api/pricing` 中的 `supported_endpoint` 与模型级 `supported_endpoint_types`。账号目录与公开接口绑定取交集，公开定价目录不当作账号授权。
- 图片按站点明确声明的 `/v1/images/generations` 合同；视频按当前声明的 multipart `/v1/videos` 与 `/v1/videos/{video_id}`。同名模型在别处的旧路径不自动套用。
- 仅配置有完整请求、查询与结果合同的模型。未声明的时长、尺寸、分辨率和参考能力不从名字、价格或计费 schema 推导；待补项在设置中展开查看。支持自定义服务继续补充其他合同。
- 视频完成后优先使用有效结果地址；没有地址时，按明确声明的同源 `/content` 接口鉴权读取。失败保留任务编号，可继续查询，不重提生成。

Key 不回显，保存到宿主凭证服务，也可仅本次会话使用。公开接口资料读取不带 Key。更换 origin 不复用原凭证，认证、网络或接口资料失败时保留原配置。保存成功后，已打开的画布刷新各自绑定的模型目录；媒体设置中的 Codex CLI 连接收在可展开区域。

## 验证范围

离线与本地服务回归覆盖目录与接口交集、错误 Key、元数据反证、未知模型、旧配置/凭证保护、重启、会话隔离、取消和原子提交排空；multipart 与结果回取用自有夹具检查，浏览器联验使用明确标识的账号目录夹具。公开站点路由单独实时核对。

本轮未读取用户该站点的真实 Key，未提交计费生成。真实账号最终可见模型、余额、生成权限与成片质量，以用户在设置中录入 Key 后的实际结果为准。默认兼容合同不代表 OpenAI 官方仍提供同名第三方模型。

Mac ARM 与 Intel 分别提供安装包和完整源码。兼容基线与安装保护沿用 [安装说明](../installation.md)；Windows 继续三平台构建验证，正式下载保留历史 v0.5.0，未新增 Windows 桌面发行包。
