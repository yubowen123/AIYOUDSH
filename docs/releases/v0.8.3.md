# v0.8.3 易用性与异常恢复

本轮从 v0.8.2 进行全模块源码审查、隔离故障复现和官方宿主关键流程检查。优先处理错误操作对象、草稿丢失、异常后无法继续和确认内容不一致；沿用既有主题与素材配色规范。

## 行为变化

- 任务上下文、输出偏好、输出目录、对话副本和用量面板正确读取原生标签页的对话参数；未指定对象时不悄悄操作最新对话。保存期间与迟到响应受到身份检查。
- 上下文恢复自动提取成为待保存草稿，保留只读约定和参考字段；Skills 创建失败保留输入，详情错误可见，星标键盘不误开详情；倒计时按本地时钟更新。
- 画布项目及创作工具区分加载、失败与空结果，提供重试。素材弹层覆盖的同面板背景不可操作，焦点进入弹层并能跨 iframe 循环、Escape 取消、关闭后恢复；其他聊天区可用。共享镜像保留实际媒体类型。
- 媒体服务切换和刷新先保护草稿；删除配置须确认，失败保留输入。临时服务不误删持久凭证，多产物任务恢复复用已经校验入库的原件，不重新提交模型生成。
- 竞技场的异步目录和准备结果与当前输入绑定，服务端确认票据固定准备内容与幂等标识。仍需显式配置 MCP；本轮未接通或调用外部生成。
- 画布回执迟到不会阻塞后续命令，导入按真实原件身份确认；项目状态仅在写入成功后发布，资产改名具有可恢复记录与故障回滚。

## 验证与边界

验证结果以本轮交付目录“系统全面审查-2026-10-26”的完整报告与回执为准。正式官方基线仍为 macOS arm64 `0.2.1-rc.2 / 332895e`；新版增强需要完整重启后加载。官方应用包不修改。

本轮不调用供应商模型、不提交付费生成、不读取用户 API Key、不操作正式项目数据。文档合同、配置保存、凭证存在与账户真实生成通过是不同结论。Windows 桌面、原生目录选择系统窗口的成功选择、全部主题与每项业务的组合，以及外站内部行为未在本轮全部重新验收。

还需持续完善：大项目搜索/排序和导入落点防重叠；多任务统一状态与失败诊断；模型参数的结构化编辑；尚未接通的可选通道及跨平台验收。完整的优先级、影响与覆盖矩阵见本轮审查报告，不据此宣称系统已无遗漏。
