## 新增与调整

- Windows C#/WinForms 中文图形安装器，使用 .NET Framework 4.8，按当前用户权限运行。
- 识别或手动选择官方 `DeepSeek Harness.exe` 所在目录，校验 `resources/app.asar` 及对应组件。
- Windows 使用目录 junction 接入模块；共享安装器保留原备份、升级、卸载和用户编辑冲突保护。
- 优先使用 Node.js 24；无独立 Node 时检测官方内嵌 Node 24.21.0 的 RunAsNode 模式。
- 独立 Windows 官方基线和 335 个语义 CSS class 映射，覆盖主题引用；保留原生 Windows shell。
- 目标构建支持 `--platform win32-x64|darwin-arm64` 与 `--out`，新增 Windows 打包入口。

两平台保持 15 个运行模块、主题与动效配置、MOKE 原生 Browser、会话视图与顶部对话工具；Claude Code 模块继续移除。

## 兼容

官方版本为 `0.2.1-rc.2`，构建为 `332895e0f7c9d4dbfb29729f5eb367fa263ff986`。每个平台使用自己的 ASAR 和组件哈希，不同平台安装包不能互换。当前支持 Windows 10/11 x64 与 macOS Apple Silicon arm64；Mac Intel、Windows ARM 尚未列为支持。

Windows 需 .NET Framework 4.8；源码构建需 Node.js 24。Mac 仍保留旧增强目录和 schema 1 回执兼容，v0.4.0 用户可使用新安装器更新。

## 验证范围

- macOS 图库来自 v0.4.0 官方宿主实际加载后的界面与安装器，继续展示共用功能设计。
- Windows 验证覆盖目标包括源码构建、独立平台/组件核对、原生 WinForms 编译与 GUI 自测、共享安装器真实 junction 隔离事务；具体运行结果以本次 GitHub Actions 及发布记录为准。
- Windows 安装器自身的 CI 渲染图只说明安装器界面，不是用户 Windows 宿主聊天截图，也不能代替实际宿主加载、动态背景和聊天交互验收。

Windows 宿主聊天、动态背景和完整交互仍需实机验收；安装器自测不包含这些项目。

## 保持的功能边界

机甲是 4 秒静音背景循环，尚无原版事件状态机、声音、轮播或媒体上传页。其他主题为静态图或明确中性回退。部分资产/看板模型执行与语义检索仍有适配或配置要求。[完整功能范围](../features.md) · [主题清单](../themes.md)

源码交付是可编辑 JavaScript 恢复分区、新增扩展与本地服务，不是完整官方 TypeScript 工程或独立官方 fork。
