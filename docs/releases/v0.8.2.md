# v0.8.2 资产库配色收敛

本版包含 [v0.8.1](v0.8.1.md) 的目录扫描、画布插入、文档自动配置媒体通道及可读配色修复。官方基线仍为 macOS arm64 `0.2.1-rc.2 / 332895e`，加载新版增强需要完整重启应用。

用户指出机甲主题下资产库大面积橙色与 DSH 钢蓝界面突兀。计数、项目头像、选中态、添加目录与加入画布等操作重新按层级配色：钢蓝与石墨表面承载内容，冰白文字保证阅读，小面积冰蓝表示交互。警告、错误和成功保留实际状态语义，普通动作不使用警告色。作品图片、视频、图形和导出像素不改色。

主题专属适配限制在本机资产页面及其弹层，普通库和画布选择器一致。切换其他主题继续同步；用户显式自定义强调色受到保留，未改写原始主题配置。按实际渲染结果检查文字、关键边界和窄窗布局，不以单纯色值替换代替验收。

模型自动配置仍读取公开关联文档和带类型目录，完整合同一键保存，未知合同单列待补；不以配置成功代表真实计费生成通过。Windows 和第三方跨域页面未在本轮扩展验收。
