# AIYOUPLUS 与 AIYOUDSH 融合

本功能作用于 AIYOUDSH 插件。官方应用、当前对话、主题和原有素材库继续由 DSH 管理。AIYOUPLUS 提供原画布与本地创作引擎，不启动另一套桌面应用或账户系统。

## 使用

1. 左侧「画布」先展示本地项目列表，支持新建、重命名、打开和返回列表；没有对话时也可使用。有对话时在原生右侧工具区打开，保留中间聊天。已有项目及其原文档继续可访问。
2. 在 DSH 对话里请求列出项目、打开指定项目、创建/修改节点、连线、插入素材或执行已配置生成节点。宿主注册 `canvas_projects/canvas_open/canvas_capabilities/canvas_snapshot/canvas_apply/canvas_assets/canvas_models` 七个真实工具。未选择项目时拒绝写入，先读实际状态，再按 revision 执行，成功回执包含实际保存文件校验。
3. 画布原放大镜和素材库入口直接打开 DSH 现有素材库，保留缩略图、搜索与筛选；选中素材后插入当前项目并保存，顶部不再重复设置插入按钮。协同查看视图可用「素材库」打开同一入口，DSH 素材卡也可拖进画布。原件与生成产物使用稳定 ID；改名和移动保留引用，被画布引用的原件受到删除保护。画布内部缓存用于预览和重开，可重建，不是第二个素材库。
4. 「创作工具」恢复 PLUS 完整的 22 个工具模块，包括 12 个图像与创作工具、10 个图形与纹理工具。依赖模型的工作区使用明确配置的媒体 API；未配置时禁止提交。工具产物回到 DSH 素材库，可发送至所属项目。
5. 「媒体模型」输入 API 文档网址后读取和分析关联接口，使用 DSH 当前文字模型辅助生成候选配置；核对后保存。支持官方及自定义第三方接口、请求头认证、模型参数、参考图、异步任务查询和结果提取。未知接口资料明确列出，不能凭空推断。

## 主题与画布外观

七套内置主题加系统默认统一作用于本机画布、创作工具、媒体模型、素材库、项目看板和原生信息面板；授权同源内嵌页面递归同步，协同查看视图使用同一组画布颜色。

主题页的「画布与自由工具」提供 9 项颜色、4 项底色透明度、主题图/底色/透明背景，以及背景图强度、位置、铺满/完整显示和网格样式、间距、强度。画布原有外观入口直接定位到这一配置区域。默认配色跟随当前主题，关闭后可单独指定；配置按主题保存。界面底色与媒体像素分离，原图、视频、3D 舞台和导出内容不套主题滤镜。

系统默认读取宿主真实亮暗与计算颜色，不覆盖宿主主题令牌，仍可单独配置画布。保存值会同步到其他宿主窗口；未保存预览留在当前窗口，其他窗口的保存不会直接替换草稿。收到更新后可取消采用最新保存值；再次保存前须刷新并通过 revision 检查。MOKE 仅原生 Browser 容器随主题，外站内部不注入。详见[主题说明](../themes.md)。

## 模型与数据

文字请求走 DSH 当前会话模型选择，不复制文字模型 Key。「媒体模型」中的 Codex 卡直接连接本机 CLI，复用 CLI 已有登录；提供路径、检测、连接和断开，不发起额外 OAuth，也不替换当前选择。连接后以 `codex-cli` 注册到 DSH 原生模型选择器，目录来自本机 CLI。尚未登录时提示先在终端完成登录。CLI 不支持的显式请求参数会在提交前拒绝；工具调用仍由 DSH 调度和权限系统执行。

图片、视频、配音和音乐服务的 Key 由宿主凭证服务管理，也可仅当前会话使用。改变服务 origin 或认证绑定会清除旧绑定，页面不回显 Key。支持明确声明的图片、视频、音频参考，以及同尺寸图片蒙版；接口没有声明能力或映射时，在请求前明确拒绝。测试服务不会成为产品默认服务；Wuread 仅测试用途。

项目与缓存存储在 `${DSH_HOME}/aiyou-enhancer/canvas/`，媒体原件由现有 DSH 素材服务单独管理。浏览器 Storage、IndexedDB 和 SQLite 均隔离到项目。上传/导出/缓存只能写入当前插件拥有的目录，共享原件不能被缓存清理删除。

## 执行与恢复

同一项目可由多个 DSH 对话打开。一个视图持有原画布编辑器，其余显示实际节点、连线和原件的实时协同视图；所有对话都可发送操作指令。点击「取得编辑权」先保存并交接原编辑器，不进行多编辑器覆盖或 CRDT 合并。关闭一个视图只释放该面板，其他对话继续使用。

画布写操作共用项目队列，使用唯一 requestId 和当前 revision。同 ID 同参数复用真实回执，不同参数拒绝；过期编辑令牌拒绝写入。保存校验同时验证原 payload 和增量 patch，重开使用原项目读取器恢复。

画布「更多工具」和固定工具栏仅保留剪辑时间线、3D 导演台、全局视角、预览与拼图、角色库、导出项目、项目管理七项。角色元数据按项目保存，图片引用 DSH 原件并受删除保护。导出使用原项目包，项目管理返回原生项目列表。

生成节点的启动回执与供应商媒体完成分开。停止只停止本机等待，服务器任务可能继续。异步恢复查询原 taskId；已有付费生成的结果回执不会因为下载失败而重复提交。对状态不确定的旧请求拒绝盲目重提。

## 验证与边界

- v0.8.0 的主题计算色、原生源样式探针、真实浏览器交互、系统与嵌套生命周期分开记录；证据位于本任务交付目录「DSH全插件主题适配」，具体报告索引见 [v0.8.0 说明](../releases/v0.8.0.md#验证与边界)。主题验收不代表模型业务重新生成通过。
- 自动测试、真实浏览器业务、实际官方宿主插件菜单与完整重启分层验收。v0.7.1 素材库替换证据以本任务交付目录「画布素材库替换」的验收清单为准；「画布项目工具完善」保留 v0.7.0 证据；「融合设计」保留 v0.6.0 历史证据。
- 浏览器业务覆盖原画布创建/保存/重开、统一原件预览、关闭立即重开、媒体处理、流水线、3D JSON/GLB、生产模板与项目存储隔离。
- 模型通道使用受控 HTTP 模拟服务与宿主适配夹具验证。CLI 版本、已有登录和模型目录另有真实只读检查；本轮没有发起真实 CLI 推理或供应商计费生成，也没有代用户完成 Codex 登录。
- 本次媒体二进制为 macOS arm64、声明最低 macOS 26；Windows 可维护源码保留，但新画布的 Windows 桌面、媒体二进制尚未验收。可通过 DSH_FFMPEG_PATH/DSH_FFPROBE_PATH 指定适配本机的工具。
- 旧 PLUS 账户、云存储、独立素材库、独立扩展桥和独立 HTTP 生产网关不启用。生产能力通过 DSH 原生工具与当前画布协调器提供，不沿用旧网关。

## 开发

原画布共享作用域的 41 个恢复分片保存在 `aiyou/vendor/aiyouplus-canvas/src/`，构建脚本在内存做精确集成变换。不要分别 import 分片，也不要编辑生成的 canvas.js。

`npm run build` 自动重建画布并组装 18 个运行模块。`npm test`、`npm run verify` 及 `node --test aiyou/vendor/aiyouplus-canvas/test/runtime-host.test.mjs` 检查宿主集成、素材、模型和本地引擎。浏览器专项脚本与可调用动作规范在 vendor 的 README/actions.json 中。

插件安装器核对官方 0.2.1-rc.2 / 332895e 基线和 ASAR 哈希，保留私有备份和卸载回执。不要通过改写兼容哈希跳过检查；完整官方应用和用户 profile 不进入交付包。
