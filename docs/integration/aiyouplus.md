# AIYOUPLUS 与 AIYOUDSH 融合

本功能作用于 AIYOUDSH 插件。官方应用、当前对话、主题和原有素材库继续由 DSH 管理。AIYOUPLUS 提供原画布与本地创作引擎，不启动另一套桌面应用或账户系统。

## 使用

1. 左侧「画布」打开画布；没有对话时也可打开本地画布。有对话时在原生右侧工具区打开，保留中间聊天。
2. 在 DSH 对话里请求打开画布、创建/修改节点、连线、插入素材或执行已配置生成节点。宿主注册 `canvas_open/canvas_capabilities/canvas_snapshot/canvas_apply/canvas_assets/canvas_models` 六个真实工具。先读实际状态，再按 revision 执行，成功回执包含实际保存文件校验。
3. 「插入 DSH 素材」是统一素材库的选择入口；原库素材卡也可拖进画布。原件与生成产物使用稳定 ID；改名和移动保留引用，被画布引用的原件受到删除保护。画布内部缓存用于预览和重开，可重建，不是第二个素材库。
4. 「创作工具」包含媒体处理、图像工作流、3D 工作台、生产模板。工具产物回到 DSH 素材库；生产操作连接当前真实画布。
5. 「媒体模型」输入 API 文档网址后读取和分析关联接口，使用 DSH 当前文字模型辅助生成候选配置；核对后保存。支持官方及自定义第三方接口、请求头认证、模型参数、参考图、异步任务查询和结果提取。未知接口资料明确列出，不能凭空推断。

## 模型与数据

文字请求走 DSH 当前会话模型选择，不复制文字模型 Key。在「媒体模型」的 Codex 卡点击「启用 Codex 模型」和「连接 Codex」，按宿主提示选择浏览器或设备验证码方式；成功后在 DSH 模型选择器选择 Codex。Codex 使用 DSH 自带的模型通道与授权流程；通道存在、账户已授权和真实调用成功分别展示。当前宿主不支持强制 `tool_choice=required` 等选项时会在请求前拒绝，避免静默丢参数。

图片、视频、配音和音乐服务的 Key 由宿主凭证服务管理，也可仅当前会话使用。改变服务 origin 或认证绑定会清除旧绑定，页面不回显 Key。测试服务不会成为产品默认服务；Wuread 仅测试用途。

项目与缓存存储在 `${DSH_HOME}/aiyou-enhancer/canvas/`，媒体原件由现有 DSH 素材服务单独管理。浏览器 Storage、IndexedDB 和 SQLite 均隔离到项目。上传/导出/缓存只能写入当前插件拥有的目录，共享原件不能被缓存清理删除。

## 执行与恢复

画布写操作使用唯一 requestId 和当前 revision。同 ID 同参数复用真实回执，不同参数拒绝；画布关闭立即释放本机等待。保存校验同时验证原 payload 和增量 patch，重开使用原项目读取器恢复。

生成节点的启动回执与供应商媒体完成分开。停止只停止本机等待，服务器任务可能继续。异步恢复查询原 taskId；已有付费生成的结果回执不会因为下载失败而重复提交。对状态不确定的旧请求拒绝盲目重提。

## 验证与边界

- 自动测试、真实浏览器业务、实际官方宿主插件菜单与完整重启分层验收。最终证据以本任务交付目录「融合设计」的验收清单为准。
- 浏览器业务覆盖原画布创建/保存/重开、统一原件预览、关闭立即重开、媒体处理、流水线、3D JSON/GLB、生产模板与项目存储隔离。
- 模型通道使用受控 HTTP 模拟服务与宿主适配夹具验证。本轮没有重新发起供应商计费生成，也没有代用户完成 Codex 登录。
- 本次媒体二进制为 macOS arm64、声明最低 macOS 26；Windows 可维护源码保留，但新画布的 Windows 桌面、媒体二进制尚未验收。可通过 DSH_FFMPEG_PATH/DSH_FFPROBE_PATH 指定适配本机的工具。
- 旧 PLUS 账户、云存储、独立素材库、独立扩展桥和独立 HTTP 生产网关不启用。生产能力通过 DSH 原生工具与当前画布协调器提供，不沿用旧网关。

## 开发

原画布共享作用域的 41 个恢复分片保存在 `aiyou/vendor/aiyouplus-canvas/src/`，构建脚本在内存做精确集成变换。不要分别 import 分片，也不要编辑生成的 canvas.js。

`npm run build` 自动重建画布并组装 18 个运行模块。`npm test`、`npm run verify` 及 `node --test aiyou/vendor/aiyouplus-canvas/test/runtime-host.test.mjs` 检查宿主集成、素材、模型和本地引擎。浏览器专项脚本与可调用动作规范在 vendor 的 README/actions.json 中。

插件安装器核对官方 0.2.1-rc.2 / 332895e 基线和 ASAR 哈希，保留私有备份和卸载回执。不要通过改写兼容哈希跳过检查；完整官方应用和用户 profile 不进入交付包。
